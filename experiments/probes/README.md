# Probes

Exploratory scripts, kept because they were run against the real corpora while the design was
being settled and some of their output is quoted in `experiment_plan.md` §12.1. They are not part
of the pipeline; nothing in `experiments/` calls them.

They lived only in the cluster work directory until 2026-09-26 and were never under version
control. Their absolute paths — which named the work directory and the account holding it — were
rewritten to `PSEUDONYMKIT_WORK` and `PSEUDONYMKIT_CORPORA` before committing, so the committed
text is equivalent to, but not byte-identical with, what ran.

Which probe produced which figure in §12.1 has not been established. The match was made on their
print statements, not by reading or re-running them; treat the mapping as unverified.
